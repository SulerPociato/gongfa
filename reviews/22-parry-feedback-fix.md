# 承雷反馈 + 保底跨刷新（2026-11-26 下午·第二轮）

> 玩家反馈：①承雷节奏反馈不够、视觉冲击不够强；②连续三次渡劫失败，运气太差。
> ②不是运气问题：`attempt` 原来只在内存，刷新一次就回到 1，第 3 次保底被刷新吃掉了。
> 方案与三遍审查见 [reviews/21-parry-feedback-plan.md](21-parry-feedback-plan.md)。

## 一、先修「不是运气」的那一半

### 改前

- `attempt` 只活内存：`runtime.restore()` 写死 `attempt = 1`；HUD 文案还写着「刷新清零」。
- 玩家失败一次 → 刷新 → 再失败 → 刷新 → 第 3 次仍是「第 1 次」，保底永远不触发。
- 实测（`p2-pity-debug`）：失败后 `gongfa:pity` 不存在；刷新后 `attempt=1`。

### 改后

- 新元进度 `gongfa:pity`：`{ realm, attempt }`，**不带槽位**（A/B 每 30 秒轮换，按槽存会像 `gongfa:dao` 一样丢）。
- 启动时同境界才恢复；`restoreAttempt` 夹 1..3；成功/换境/清档清掉。
- HUD：「刷新清零」→「本档记录」；第 2 次失败后常驻「再失败 1 次，下一发必成」；第 3 次变金色「本发保底必成 —— 不会再有第 4 次」。
- 失败结果层副标直接写「下一发保底必成」或「再失败 N 次必成」。
- 契约 §7.1 已补这条（2026-11-26 修正）。

### 证据

| 场景 | 改前 | 改后 |
|---|---|---|
| 失败一次后刷新 | attempt=1，无 pity key | attempt=2，key `{"realm":0,"attempt":2}`，HUD「第 2 次冲关 · 再失败 1 次，下一发必成」 |
| 恢复 attempt=3 | — | HUD「第 3 次冲关（保底必成）」+ 金色提示；10 秒不接雷仍「突破成功」+「保底第 3 次，非骰值」；成功后 attempt=1、pity 清除 |
| 同一会话连败两次 | 第 3 次必成（单测） | 仍必成（`runtime.test` 新增：seed 73 前两发骰都烂，第 3 发 forced） |

## 二、承雷反馈重做

面板现在是：

```
渡劫 · 炼气 → 筑基                     成功率 87%
[心魔 ▓▓░░]        [●───●───●]  [10s 进度条]
        下一波 2.4s · 承雷窗口 ±700ms
[ 承雷 ]  [ 交给天意 60% ]
```

- **成功率实时显示**：`parryRate(hits, 已漏波数, demon)`，接住 +2%、漏 −5%、心魔档位扣 10/20%，颜色 ≥85 青 / 60–85 金 / <60 朱；数字每次变化弹一下。
- **三波时间轴**：下一波呼吸脉冲 + 外扩光圈；命中 ✓、漏 ✗（按波次，上一轮已修）；10 秒进度条 + 2/5/8 秒刻度。
- **命中**：整屏青色闪光（portal 到 body，z 109 低于面板 110，面板文字不被洗白）+ 对角线雷光 + 面板/画布震动 + 画布瞬间提亮 + 飘字「承雷 +2%」+ 外扩环 + 手机震动 28ms。
- **漏雷**：朱红整屏闪光 + 更强震动（280ms）+ 画布色相偏红 + 飘字「漏雷 −5%」+ 手机 60ms。
- **结果层**：失败副标带保底进度；成功且 forced 时显示「保底第 3 次，非骰值」。

### 过程中修掉的两个自己引入的问题

1. **震动把面板甩出屏幕**：WAAPI 的 keyframes 整体替换 `transform`，丢了面板自身的 `translateX(-50%)`；390×844 实测面板 x=198、右边超出视口。现在每帧都带 `translateX(-50%)`，实测 x=19、宽 358、不溢出。
2. **进度条严重滞后**：`width` 过渡每次被新目标重启，实测 68% 时间点只画到 36%。去掉 `transition: width`，现在 computed = 374 × inline%（12.1/42.1/62.2/87.3 四处一致）。

## 五、取舍 / 未做

- **冷却 60 秒仍不跨刷新**：刷新可跳过冷却，但不会跳过保底；本轮没动，避免一次改太多。
- **悟道仍刷新清零**：契约 §7.1 原样；它是货币，丢了玩家会疼，但本轮不在范围。
- **没有音效**：仓库没有音频资产；震动 + 闪光 + 飘字已经足够，加音效要另做静音开关。
- **保底全局共享**：同浏览器换档会共享 pity；换槽不丢的代价，可接受。
- **闪光强度**：`p1-miss.png` 整屏偏红较强；如果嫌吵，调 `.trial-flash` 的 alpha 即可（一行 CSS）。
