## 一、13 个功法图案的可发现性

做法：给每个图案各造一份画布（独立新档），编译后打开图鉴读「已发现」列表。

| 图案 | 造法 | 结果 |
|---|---|---|
| 直行吐纳 | 单块吐纳 | ✅ |
| 周天循环 | 循环 3 次 { 吐纳 } | ✅ |
| 清心诀 | 如果 心魔>0.5 { 调息 } | ✅ |
| 玉简缓存 | 循环 3 次 + 装备玉简 | ✅ 周天循环 + 玉简缓存 |
| 见好就收 | 循环里 预算<50 → 中断 | ✅（同时点亮 自适应周天、护体真气） |
| 不定周天 | 重复直到 心魔<0.9 { 吐纳 } | ✅ 周天循环 + 不定周天 |
| 自适应周天 | 循环 2 次 { 如果 心魔>0.5 { 调息 } } | ✅ 清心诀 + 自适应周天 |
| 大小周天 | 循环 2 { 循环 2 { 吐纳 } } | ✅ 周天循环 + 大小周天 |
| 换气 | 如果（两个分支都有动作） | ✅ 清心诀 + 换气 |
| 护体真气 | 循环里 预算<40 → 中断 | ✅ 见好就收 + 自适应 + 护体真气 |
| 掐指一算 | 循环里 心魔>0.7 → 中断 | ✅ 见好就收 + 自适应 + 掐指一算 |
| 一气呵成 | 直列 6 块吐纳 | ✅ |
| 分批吐纳 | 沙漏包一块吐纳 | ✅ 直行吐纳 + 分批吐纳 |

**结论**：13 个图案全部可由玩家自然搭出并识别，无需依赖藏经阁抄录。

### 抓到的 bug（已修）

**演示跳关 / 离线突破后，道具文案显示旧境界。**
原因：道具面板用 `game.realm`（只在落盘时更新）算解锁，而 runtime 的境界已经变了。
表现：金丹期仍显示「灵珠 · 筑基解锁」。
修法：改用跟随 runtime 的 `artifactRealm`，境界一变就重算持有与解锁文案。
