# 渡劫·承雷（2026-11-26）

## 一、要解决的问题

原来的渡劫只有一次决定：点一下 85%，不点就 60% 托管。10 秒里**没有操作、没有信息、没有紧张感**。

玩家原话：「想在渡劫时加点实时策略的紧迫感」。

## 二、设计（用户拍板：靠节奏格挡压心魔 / 进场自己选）

- **三波天雷**：进窗口后 2s / 5s / 8s，界面上一排三个雷点。
- **承雷**：雷点 ±700ms 内点「承雷」算命中 → 心魔 −12%、成功率 +2%。
- **漏波**：自动记 miss → 心魔 +16%、成功率 −5%。
- **心魔上涨**：渡劫期间 5%/秒，不接雷就会掉档；结算时 ≥60% 再 −10%，≥80% 再 −20%。
- **成功率**：85% 起，夹在 55%–95%。
- **两个出口**：窗口里点「承雷」继续接；点「交给天意」立刻按 60% 结算（原语义）。
- **不选模式**：进场就是普通渡劫，玩家在窗口里自己决定接不接雷——不接就自然落到 60% 档。

这样三个档位都还在：**85%（基准）/ 60%（托管）/ 55–95%（承雷）**，契约端点没被改。

## 三、实现

| 层 | 改动 |
|---|---|
| core `realm/rules.ts` | `ChallengeMode` 加 `'parry'`；`TRIAL_WAVES_MS`、`TRIAL_PARRY_WINDOW_MS`、`PARRY_*` 常量；`parryRate()`；`resolveChallenge` 按 mode 选率 |
| runtime | 渡劫期间心魔按真实时间上涨；`parryTrial()` 判定命中（同波只算一次，拍空不罚）；到期按 `parry` 结算并补记漏波 |
| HUD `TrialPanel` | 心魔条 + 三雷点 + 「承雷」/「交给天意」；`ChallengeModel` 透传 `trialParry` |

## 四、实测

```
ENTER   panel=true waves=3 hit=0 demon=7%  next=下一波 1.6s
PARRY-1 panel=true waves=3 hit=1 demon=5%  next=下一波 2.7s   ← 命中：心魔降、雷点亮
MID     panel=true waves=3 hit=1 demon=14% next=下一波 0.9s   ← 没接，心魔回升
END     panel=false result=突破成功                            ← 10 秒到期结算
EXC 0
```

单元测试：`parryRate` 四档（全中 91%、中二漏一 84%、心魔档位、夹取 55–95）全部通过；全套 **632 通过**。

## 五、取舍

- **没有难度选择**：按用户要求，改为窗口内自选（承雷 / 交给天意），设置里不加开关。
- **心魔上涨只持续 10 秒**，不会把渡劫前的心魔推到 80% 以上——除非本来就高。也就是「渡劫会放大你原本的风险」，而不是凭空制造风险。
- **不接雷 = 60%**：与旧版托管完全一致，挂机玩家没有损失。
