# 字体

- JetBrains Mono（数字/代码）：OFL 1.1，来自 @fontsource/jetbrains-mono
- Noto Serif SC（标题/古风）：OFL 1.1，来自 @fontsource/noto-serif-sc

得意黑（Smiley Sans）未下载：npm 无包、GitHub Release 下载超时。可后续手动补 SmileySans-Oblique.ttf。

用法（CSS）：
@font-face { font-family: "JetBrains Mono"; src: url("./assets/fonts/jetbrains-mono-latin-400-normal.woff2") format("woff2"); }
@font-face { font-family: "Noto Serif SC"; src: url("./assets/fonts/noto-serif-sc-chinese-simplified-400-normal.woff2") format("woff2"); }
